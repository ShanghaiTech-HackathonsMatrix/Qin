## 构建

在仓库根运行 `npm run sync:ios -w matrix-shell`。Mac 安装依赖后，在本目录运行 `ruby configure_widget_target.rb`（需要 Ruby 的 xcodeproj），再使用 Xcode 打开 `App/App.xcodeproj`。

脚本注册两个 Widget 的扩展 target、原生桥源文件及 App Group。真机签名时，App 与扩展须使用同一开发团队，并具备 `group.dev.matrix.shell` 的共享容器权限。

## 灵动岛第一阶段

后续视觉修正：用户确认灵动岛出现/收起，但原 SwiftUI 模糊描边在真机看不到明显辉光，光晕视觉尚未验收。改为预合成透明光环纹理，所有辉光保留在紧凑呈现的边界内；本机已检查黑底合成效果，真机显示仍需确认。纹理由 render_refresh_halo.ps1 生成，不含外部模型。用户进一步澄清要增强的是整个灵动岛外沿，非小图标光环：小图标已恢复紧凑 26 点、展开与锁屏 40 点及单层光环，右侧恢复文字。外沿 keylineTint 改为青白色；Apple API 仅提供 subtle border tint，没有外沿粗细或辉光半径参数，不声称实现了扩大外部光晕。组件排队与结束提示从 WidgetKit 生成新反馈时间线起展示约 5 秒后隐藏，避免启动延迟耗尽提示时间，只隐藏提示，不清除请求或改写同步结果；实际切换时刻受 WidgetKit 时间线调度影响。

共享刷新 Intent 改为 LiveActivityIntent，启用 NSSupportsLiveActivities，扩展添加 ActivityConfiguration。点击后显示短暂青色光晕与明确的排队/未登录提示，约 3 秒主动结束；主 App 在此窗口内开始或完成同步时可更新状态。不将请求已写入表示成联网完成，不依靠 staleDate 自动移除活动。

本阶段只提供刷新请求反馈，尚未完成整个联网过程的持续展示、平台确认提交的划除效果或 3D 资源渲染。没有提交确认时不会展示完成动画。系统禁用 Live Activities 时不阻断组件请求；可从本机诊断键 ddl.widget.activityError 查看启动错误，不包含平台数据。
