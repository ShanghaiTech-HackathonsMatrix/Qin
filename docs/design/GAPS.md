# 当前缺口与验证边界

更新：2026-10-18。此表取代早期“仅内置、沙箱未开始”的阶段判断；历史可从 Git 查看。

| 项目 | 当前进度 | 剩余工作 |
|---|---|---|
| 内置学业插件 | Android 会话、课程/作业/排课、投影与提醒已实现 | 多账号/站点改版持续回归；非当前学校 BB 不保证兼容 |
| BB 快速同步 | 真实门户的待完成模块与明确空状态已识别；目录回退可手动启动 | 真实非空待完成样本尚待验证；合成测试不代表所有网站结构 |
| 失败与旧作业 | 成功页增量保留；消失项待确认，每轮最多核对 8 条 | 不推测列表消失即已提交；平台无法判断时保持待确认 |
| 首页与设置 | 自然滚动、字号适配、四类设置入口；本机最大字号验收通过 | 特殊屏幕及系统辅助字体持续回归 |
| 任务与外链 | 顶部多选分类计数，作业/BB课程系统浏览器链接 | 浏览器会话与应用登录不共享，浏览器可能需要登录；不做教务-BB自动匹配 |
| 自定义日程 | 单次/每周/全天/地点/备注/提醒 | 不支持单次例外、复杂RRULE；当前按开始日展示跨天事件 |
| 课程 | 平台字段只读、备注可改；保留首周/作息设置 | 首周需用户填写；不自动猜测 |
| 教务网页登录 | 仅显示学期选择的页面也能同步新课表，不据空白判断过期 | 网页课表空白的渲染原因尚未定位；同步与网页显示分开验收 |
| 外部安装 | .mtp 校验、权限确认、持久化、启停和卸载 | 无市场、签名验证或自动更新；版本升级需卸载保留数据再安装 |
| 沙箱 | 每插件独立 QuickJS WASM；内存/时间限制、JSON桥 | 主线程执行，未迁移 Worker；资源上限不能等价于完全无卡顿 |
| 外部权限 | 计划式网络、实体/槽、UiNode、命令 | auth/secrets、通知、文件导入、fs、db.raw、后台、模型、流式处理暂拒绝 |
| 身份与信任 | 内置与外部路径分离、外部明确未验签 | installBuiltin 独立类型入口、密码学签名、信任记录持久化仍待完善；安装与启停已独立持久化 |
| 读取边界 | 外部控件按 data.read 与 requires 选数据、跨所有者字段投影 | 底层 DataBus/read 是宿主低层接口，不能直接给外部代码使用 |
| Cookie | BB/GS/EAMS 凭证在独立原生进程，外部无该会话桥 | 通用 CapacitorHttp 的任意外部插件间 Cookie 隔离仍需后续设计 |
| 通知 | Android 原生桥、宿主提醒调度 | 个人事件预排未来31天、最多100条，依赖启动/回前台补排；iOS未验收 |
| Web SQLite | 现状保留 | 本轮按用户决定不修；降级后的索引/持久化/性能不应假定与原生一致 |
| 工具与文档 | pack/validate、示例、AI Skill | 无 create/build/sign/dev 全套CLI；校验不替代VM或真实网站测试 |

## 验证分层

自动测试应验证纯函数、网关、沙箱、生命周期与持久化失败语义；APK 编译只证明打包可行。手机文件选择、WASM/CSP、真实网站与系统外链需真机确认。具体见 [设备验收](../testing/2026-10-18-android.md)。

真实页面、Cookie、设备日志和 APK 不提交。测试样本要脱敏，尤其非空 BB 列表不要直接保存同学的账号数据。
