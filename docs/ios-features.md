## 可直接用于项目说明的简介

Qin 的 iOS 应用复用项目现有课程、作业、课表和本地数据体系，采用 React 与 Capacitor 构建，并以 Swift、WidgetKit、App Intents 和 ActivityKit 提供原生交互。用户可连接 Gradescope、Blackboard 和教务系统，在 App 内查看本学期课程、作业截止时间与课表；桌面提供 DDL 和今日下一节课两类组件，支持单击发起刷新请求，并可通过系统智能叠放在同一桌面位置切换。组件采用与 App 一致的暖白黑灰主色、iOS 磨砂材质与深浅色适配。灵动岛提供短暂刷新反馈，以及带作业标签、旋转光圈和碎片消散的 Kill DDL 完成效果。

| DDL 组件 | 每条作业占一行，显示课程、标题、截止日期与时间；长文字按空间省略。提供小、中、大三种系统尺寸，目前容量为最多 3/4/6 行，演示与短暂提示会占用行数。尺寸由用户通过系统选择，不是 Android 式自由拉伸。 |
| 今日课程组件 | 展示今天最近的下一节课，包含课程、时间、地点；开课 30 分钟后切换到下一节。无后续课程时显示空状态。时间线预设切换点，系统可能延迟实际刷新。 |
| 同一位置切换 | DDL 与课程为两个独立 Widget，可通过 iOS 系统智能叠放在同一位置上下滑动切换；不是单个 Widget 内自行处理滑动，也不承诺按无课状态自动移除系统叠放项。 |

| 组件视觉 | 暖白、黑灰与 App 主色一致，采用系统字体、SF Symbols、连续圆角、薄磨砂材质、微渐变与外围细高光；跟随系统深浅色，降低透明度时使用实色。实际透明强度受桌面宿主控制。 |
| 灵动岛刷新反馈 | 单击组件时通过 Live Activity 短暂显示刷新状态与青色视觉反馈，结束后主动收起；日常不常驻占用灵动岛。外沿色调与呈现尺寸受系统控制，不承诺任意扩大或始终自动展开。 |
| Kill DDL 演示 | 演示 DDL 实际出现在桌面组件列表中，点击“模拟提交”后从列表清除，灵动岛展示对应标签和旋转光圈碾过、碎片飞散的效果；可重新加入反复演示。演示不向网站提交作业，也不修改真实作业。 |
| 光圈素材 | 使用用户提供的 USDZ 模型离线渲染为内置透明图像，再以 SwiftUI 完成旋转、移动与碎片动画；视觉来源为真实 3D 素材，灵动岛内不运行实时 3D 引擎。 |
| 真实提交事件接线 | 新同步结果明确读到 submitted/graded 状态时，生成带课程和作业标题的完成事件，串行交给原生效果。首次历史已提交记录、个人完成勾选、列表消失或同步失败均不触发；重复快照去重。事件判定有自动测试，真实网站提交到动画的完整真机闭环未单独记录。 |

## 项目说明必须保留的实现边界

- **组件单击已接入后台原生联网引擎，不再等待前台消费请求。** LiveActivityIntent 在 App 后台进程调用 JavaScriptCore 中的共享连接器，由 URLSession 复用官方登录会话请求平台，成功后发布组件快照。首次需在 App 登录并同步一次；单次检查限时 25 秒，失败保留对应平台旧数据。后台执行与组件实际重绘仍受系统调度控制，不等于无人点击时持续实时监控。灵动岛出现只证明交互反馈，不证明平台同步成功。
- 保存的是网站会话，尚未实现 iOS 密码保存与自动重登；会话过期需重新打开官方登录页。
- 仅在明确读取平台提交状态后触发真实完成效果，不能把超时、条目消失或用户点了刷新当成已提交。
- 系统控制 Live Activity 紧凑/展开呈现及动画时机；不能保证每次自动放大。无灵动岛设备保留组件，并使用设备支持的 Live Activity 呈现。
- 当前交付为开发签名真机安装，不是 App Store 发布或可任意分发的正式 IPA。源码不包含个人团队、证书、账号、Cookie、数据库和安装包。
